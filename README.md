# Ministry Command Center

Preserved application recovered from the existing Ministry Command Center Sites source, commit `021db41172c5ab4b702f9c3922c49ec5e5c5d6e2`.

GitHub Pages serves `main` / repository root. `app.js` and `styles.css` are unchanged; `index.html` has only Mike's standing C4 footer added. The inline SVG favicon is preserved. No build or dependencies are required.

Records remain stored locally in each browser using `ministry-command-center-v1`. Existing records on the old Sites origin do not automatically transfer to this new origin. There is no shared database, login, or volunteer synchronization in this version. The original hosted site is unchanged.

This migration does not implement the planned feature expansion.
